## Reflection: Week 16

---

### The Mistakes We Made

#### 1. Excalidraw Live Bug Cascade

**Cost:** 6 bugs discovered in rapid succession after deploying Excalidraw Live (CSS imports, reload loops, type errors, font rendering, element sanitization, label stripping)
**Fix:** Fixed all 6 and extracted to standalone project same day
**Lesson Learned:** Real-time collaborative tools have a higher bug surface than static tools. Ship fast, but expect a bug-fixing sprint immediately after.

#### 2. Cumulative vs Rate-Based Metrics

**Cost:** UDM retry threshold triggered false alerts because it tracked cumulative counts instead of rates
**Fix:** Replaced with rate-based delta tracking (`ea1709adb`)
**Lesson Learned:** Cumulative counters always grow. Rate-based deltas show actual change. For alerting, you almost always want rates.

---

### The Surprising Things

#### 1. Insights Cost Was Trivially Low

**Expected:** Self-analytics would be expensive to run on every session
**Actual:** ~$0.002/session (Haiku) for extraction, ~$0.04/report (Sonnet) for synthesis

The total cost to analyze a full week of sessions and generate a narrative report is under $1. The bottleneck was never cost - it was designing facets worth extracting.

#### 2. Supplies Tracker: Audit to Production in One Session

**Expected:** Database module + API + scheduled jobs would take multiple sessions
**Actual:** 5 tables, 18 endpoints, CSV import, and 3 scheduled jobs shipped in one day

The recurring purchases audit (`a51bac4b7`) had already done the hard thinking - identifying vendors, products, reorder patterns, and data relationships. Implementation was mostly typing.

#### 3. Excalidraw Live Needed Immediate Extraction

**Expected:** Excalidraw Live would live in the andy repo
**Actual:** Extracted to standalone `~/drawbridge` project the same day it shipped

The real-time WebSocket architecture didn't belong in a knowledge management repo. Recognizing that and extracting immediately prevented coupling.
