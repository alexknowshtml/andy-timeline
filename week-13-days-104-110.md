### Subagent Spawning System

**Commit `43fb8124f`**

The subagent spawning architecture landed, inspired by clawdbot patterns:

- **Result Announcement Pattern** - Request origin tracking (Discord, CLI, webhook, Andy Core) with automatic result routing back to originating source
- **Agent-to-Agent Handoff** - Chain agents for multi-step workflows with 6 agent types (research, email-draft, code-review, task-breakdown, summarize, explore)
- **Max chain depth of 5** - Prevents runaway loops while enabling sophisticated multi-agent coordination

This infrastructure enables workflows where one agent can spawn another, and the final result flows back to wherever the original request came from.

### Behavioral Pattern Fingerprinting

**Commits `2408997c1`, `8044cf36b`**

Network tracker gained behavioral fingerprinting for device-person correlation:

- **Day-of-week distribution** - When do they usually come in?
- **Time-of-day distribution** - Morning/afternoon/evening arrivals
- **Visit frequency** - How often per week?

Cosine similarity compares person check-in patterns with device appearance patterns. A device appearing every Friday evening matches a person checking in every Friday evening.

Initial run: 89 person patterns, 105 device patterns identified.

**Lesson Learned:** Voice interfaces need clear feedback during processing. The "thinking sound" serves the same purpose as typing indicators - letting users know the system is working.

## Reflection: Week 13

---

### The Mistakes We Made

#### 1. Discord Bridge Session Recovery

**Cost:** Commits `d8b29327f` → reverted `401142b39` → fixed properly `500574d6d`
**Fix:** Third attempt addressed root cause of session recovery and output extraction
**Lesson Learned:** When a fix gets reverted, the problem wasn't fully understood. Take time to diagnose before the second attempt.

#### 2. TTS Quota Misdiagnosis

**Cost:** Debugging code for audio truncation that was actually an API quota issue
**Fix:** Identified ElevenLabs quota limits as root cause
**Lesson Learned:** Check external service limits before debugging internal code. API errors manifest in unexpected ways.

#### 3. Calendar ID Format Mismatches

**Cost:** False positive alerts for events with ID format differences
**Fix:** Multiple commits `900deba70`, `91ff0ca61` to handle format variations
**Lesson Learned:** External service IDs may have multiple valid formats. Normalize before comparing.
