## Reflection: Week 55

---

### The Mistakes We Made

#### 1. Marking Work Done Before Doing It

**Cost:** An agent wake was marked done before dispatch, so a failure lost it. Overlapping notifier runs double-reopened a snooze. A late webhook made two Nexudus passes. A failed SMS forward was silent and its resend was dropped as a repeat.\
**Fix:** `9f78ad6ba5`, `3a5074ce07`. Claim first, release on failure, tag rows `andy:pending` before forwarding.\
**Lesson Learned:** Order matters: claim, act, settle. The failure path has to put the claim back.

#### 2. A Permission Approval Trusted the Request Body

**Cost:** `/api/discord/permission-approval` believed the `discordUserId` it was given. Any tailnet device or server process could approve a permission by naming Alex's ID.\
**Fix:** `25a00d5a02` refuses anyone but Alex.\
**Lesson Learned:** A field that says who is asking is a claim, not an identity. Check it against something the caller cannot choose.

#### 3. A Rate Limiter With One Bucket for All of Localhost

**Cost:** A card-button click got a 429 on Nov 5 because every local caller shared one throttle bucket.\
**Fix:** `b437728cc0` gives each throttled route its own bucket, and the bridge now warns when Andy Core rejects a click.\
**Lesson Learned:** A shared limiter hides in plain sight until a click fails. Key limits by route.

#### 4. The Lock Watcher Lasted One Day

The Mac Mini lock watcher shipped in the morning of Nov 4 and was retired that afternoon once remote unlock worked (`fa6ad6bf49`).\
**Lesson Learned:** Build the fix for the problem first. The monitor for the problem was only needed while the fix was missing.

---

### The Surprising Things

#### 1. The Restore Test Failed With No Missing Data

**Expected:** A failed checksum meant a bad backup.\
**Actual:** Postgres stats counters reset on restart, so the test misread an in-place-updated table as append-only. Nothing was lost.

#### 2. Silence Read as a Hang

**Expected:** A dimmed spinner during a long thinking step was cosmetic.\
**Actual:** Alex typed "Stop" on a live turn because it looked dead. The first trace blamed a stop word, and a second pass found the spinner.

#### 3. Deleting Shadow Code Took a Day

**Expected:** Retiring a half-built CoS rule set would take a careful week.\

### Lessons for Building AI Systems

- **Shadow first, then enforce.** Team access control (#1529) ran deny-by-default in shadow mode, and the shadow log shaped the final rules.
- **One function owns each judgment.** The timelapse attribution rewrite replaced several local guesses with a single `attribute()`.
- **Name states.** The CoS lifecycle phases replaced a pile of flags.
- **Status signals are interface.** Spinner behavior shapes what the user does next.
