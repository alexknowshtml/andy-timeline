## Day 297: Events Pipeline, Compact Recovery Visibility, and Relationship Flags (July 25, 2026)

### The Events Venue Rental Pipeline Launches

**Commits `8ebe898ef5`, `23231c4773`, `dde8b9cacd`**

Indy Hall's venue rental pipeline got its own kanban board. Autobahn — a lightweight Kanban service already running internally — was cloned into `/home/alexhillman/services/autobahn`, registered in the PM2 ecosystem on port 4780, and wired into Caddy behind `pipeline.indyhall.org` (Tailscale-only). The initial config specified five lanes: Inquiry, Qualifying, Confirmed, Active, and Done.

The accompanying `PIPELINE.md` documented the standard booking sequence — the stages a venue inquiry moves through from first contact to event completion. Agent instructions followed the next day (`dde8b9cacd`), defining lane semantics, card format rules, what agents must not do, people and roles, and the handoff protocol. The service was renamed "The Queue" (`eb837da0a2`, July 27) — a cleaner name for a board that manages work in progress.

**Lesson Learned:** Infrastructure for a process becomes more valuable when it includes the process documentation alongside the tooling. The agent instructions aren't a nice-to-have — they're what lets Andy move cards without asking which lane something belongs in.

### Morning Relationship Flags Triage (10:30am Weekdays)

**Commit `606f47c0d2`**

A new scheduled job joined the weekday morning routine: at 10:30am, the relationship flags triage job checks for open flags. If there are none, it exits silently. If there are flags, it opens a `#workbench` thread, presents the first flag with Resolve/Snooze/Investigate buttons, and waits for a reply to continue the interactive loop — the same human-in-the-loop pattern used by morning task triage.

A small fix landed the same session (`c92c8bd185`): the job failed when Claude skipped the text preamble and went straight to buttons. Now it handles both patterns.

**Lesson Learned:** Mirroring an established pattern (morning-triage-tasks) when building a new job isn't laziness — it's the right call. The user already knows how to interact with the pattern; there's nothing to relearn.

### Compact Recovery Gets Discord Visibility (GH #455)

**Commit `153274a2be`**

Context compaction is one of Andy's least visible operations: a long session hits the context window, the post-compact hook fires, the system reinjects state, and the conversation continues. Previously this was entirely silent — no way to confirm it had fired without behavioral inference.

A new `/api/discord/compact-recovery` endpoint and a corresponding hook change post a 🧠 message to the active thread when compact recovery fires. The hook reverse-looks up the thread by session ID (same pattern as the compact-start notification) and posts the confirmation as a best-effort background curl — non-blocking, so a failed notification can't interrupt recovery.

**Lesson Learned:** Silent infrastructure is a debugging nightmare. A 🧠 message in the active thread costs nothing and eliminates the guesswork of "did that actually fire?"

## Day 299: IH20 Goes to Production (July 27, 2026)

### IH20: From Launch to Production in One Session

**Commits `5ca9430141`, `1d23873dcd`, `b83297a5e8`, `af35e7e749`, `414a0a4936`, `c518883a70`, `13a57c6361`, `400fd574d5`, `a28732e064`, `d3b35f5c17`, `6c72f46880`, `fdce128aee`, `68a3679390`, `970380ad16`, `4b429edaf1`, `125e1c95aa`, `bf9e53685a`, `5369be8ec1`, `fdbabe6333`**

July 27 was the IH20 day. Nineteen commits transformed the July 26 MVP into a production page with full asset control, an OG image pipeline, animations, and a live waitlist form.

**Asset self-hosting:** The July 26 version loaded fonts from Google and assets from Canva's CDN — fine for a first pass, not fine for a production page that needs reliable loads. A CORS error on the deployed version triggered a full self-hosting pass: Google Fonts (Barlow Condensed 400+900) downloaded and embedded (`6c72f46880`), all Canva media assets moved to the repo (`a28732e064`), and a FOUT fix added to hide transformed text until fonts were ready (`d3b35f5c17`).

**OG image pipeline:** The page needed a 1200×630 social share image. The first approach added a custom `og.html` template; two commits later it was replaced with a Playwright screenshot of the actual S1 panel (`af35e7e749`) — more accurate, no maintenance burden. Font loading required the same self-hosting treatment inside the Playwright script (`b83297a5e8`). Final positioning committed (`414a0a4936`).

**Animations:** A foil shimmer animation was added to the S2 date/time section (`fdce128aee`) — then tuned across three commits: 5s was too fast, 9s too slow, 7s landed right (`970380ad16`); the stripe tightened and button color fixed (`68a3679390`); opacity softened to 0.45 for subtler effect (`4b429edaf1`). Sparkles on the dark registration section and a collage paper-edge effect on the roses and disco ball image (`c518883a70`) followed.

**Waitlist form:** The form was wired to `POST /api/forms/subscribe` (`13a57c6361`), gained client-side email and phone validation (`bf9e53685a`), and email was made required while phone stayed optional (`5369be8ec1`, `fdbabe6333`).

**Lesson Learned:** Canva CDN assets work in preview mode and break on deployment — CORS restrictions, caching behavior, and CDN availability all differ from what the browser sees in an editor. Self-hosting is the only reliable path for production. The two-day split (launch → harden) was the right order: ship something real, then make it right.

### /pay Gets an Email Confirmation Gate

**Commits `3d8ac7ce3b`, `7bc9178654`, `1163c02e90`**

The `/pay` Mercury ACH skill gained three hardening commits:

- **Email confirmation gate** (`3d8ac7ce3b`): Before any payment executes, the script looks up the recipient's email via the Mercury list endpoint — not the individual endpoint, which returns `emails: null` (documented as a GOTCHA inline). If no email is found in Mercury or the relationship file, the payment exits with code 1. A `--dry-run` flag enables pre-flight gating. Immediately after payment, a confirmation email goes to the recipient with Alex CC'd.
- **Delivery-estimate timing** (`7bc9178654`): ACH payments initiated before noon arrive same-day; after noon Mon–Thu arrive tomorrow; Fri/Sat/Sun arrive Monday — with explicit times shown in the confirmation. Ceiling rounding on shift end times also added to the shift hour calculation.
- **Docs** (`1163c02e90`): Delivery-estimate quick reference and the Mercury email API gotcha documented in the skill for future reference.

**Lesson Learned:** Payment tooling should fail loudly before money moves, not after. An email gate that exits(1) if it can't find a recipient address is the right failure mode — better to require manual intervention than to send an ACH with no confirmation path.

### NowService: The /now Command Gets a Query Layer

**Commit `182570785e`**

The `/now` command gained a dedicated service layer. `NowService` aggregates reminders, tasks, projects, and events into a single structured response — the backend for what a "what's happening right now" query needs. `ReminderService` was refactored to support this aggregation pattern. 105 lines of new code that make the /now command's answer coherent rather than assembled ad hoc from four separate queries.

**Lesson Learned:** A command that answers "what's happening now" needs a service that knows the answer. Moving the aggregation logic into a service makes it testable, reusable, and correct.

## Reflection: Week 40

### The Mistakes We Made

#### 1. IH20: Canva CDN Assets in Production

**Cost:** The July 26 IH20 page loaded fonts from Google and media from Canva CDN. CORS restrictions broke the deployed version — assets that loaded fine in preview failed on the production domain. The self-hosting pass on July 27 required downloading and embedding all fonts and media.\
**Fix:** `a28732e064` + `6c72f46880` — all assets moved to repo; self-hosted and reliable.\
**Lesson Learned:** Never ship a production page loading assets from a CDN you don't control. Preview environments mask cross-origin restrictions that production exposes immediately.

#### 2. OG Image: Custom Template vs. Real Page Screenshot

**Cost:** The first OG image approach built a custom `og.html` template to control the layout. The result didn't match the actual page. Two follow-up commits replaced it with a Playwright screenshot of the real S1 panel.\
**Fix:** `af35e7e749` — screenshot the actual page, not a template approximation.\
**Lesson Learned:** An OG image that doesn't match the actual page is a worse experience than no OG image. When you have a Playwright pipeline, use it.

#### 3. Mercury /recipients/{id} Returns emails: null

**Cost:** The /pay email gate initially used the Mercury individual recipient endpoint to look up the recipient's email. That endpoint returns `emails: null`. The script only worked after switching to the list endpoint filtered by ID.\
**Fix:** `3d8ac7ce3b` — GOTCHA documented inline; list endpoint used.\
**Lesson Learned:** API documentation describes the schema; only runtime testing reveals which fields are actually populated. Document API gotchas in the skill where future-you will find them.

---

### The Surprising Things

#### 1. The IH20 Shimmer Took Three Tuning Passes

**Expected:** Animation speed is a one-commit decision.\
**Actual:** 5s felt rushed, 9s felt slow, 7s was right. The right speed for a foil shimmer on a save-the-date page is not derivable from first principles — it requires watching the animation play.

#### 2. The Events Pipeline Was Renamed the Same Day It Launched

**Expected:** "Autobahn" was the service name, chosen deliberately.\
**Actual:** Within hours of launch, the service was renamed to "The Queue" — a name that better describes what it actually does. The rename was a one-session realization that the first name didn't fit the thing it was managing.
