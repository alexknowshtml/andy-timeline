**Commits `5f48d7b996`, `de387416e3`, `ab6eb8b7be`, `58da1a3371`, `f25adc1dfe`, `d461e34565`, `4b052a5992`**

An inline credential guard was added as a `PreToolUse` hook (`5f48d7b996`), then extracted into a dedicated hook (`de387416e3`), then the extracted hook was removed and its functionality merged back into the write-guard (`ab6eb8b7be`) — three architectural iterations in a single session. ### /pay Gets an Email Confirmation Gate

**Commits `17d2e89053`, `a0483f9214`**

The `/pay` Mercury ACH skill gained an email confirmation gate: before any payment executes, the script looks up the recipient's email via the Mercury list endpoint — not the individual endpoint, which returns `emails: null` (GOTCHA documented inline). ## Reflection: Week 40

---

### The Mistakes We Made

#### 1. IH20: Canva CDN Assets in Production

**Cost:** The July 26 IH20 page loaded fonts from Google and media from Canva CDN. CORS restrictions broke the deployed version — assets that loaded fine in preview failed on the production domain. The self-hosting pass on July 27 required downloading and embedding all fonts and media.\
**Fix:** All assets moved to repo; self-hosted and reliable.\
**Lesson Learned:** Never ship a production page loading assets from a CDN you don't control. Preview environments mask cross-origin restrictions that production exposes immediately.

#### 2. gif-pick.ts: One Commit Forward, One Back

**Cost:** An attempt to move the GIF vision step into a standalone `gif-pick.ts` script broke the vision step and was immediately reverted (`1bed251003`).\
**Lesson Learned:** When an architecture migration breaks a critical behavior, the right move is revert-then-investigate, not patch-forward.

#### 3. Mercury /recipients/{id} Returns emails: null

**Cost:** The /pay email gate initially used the individual Mercury recipient endpoint. That endpoint returns `emails: null`.\
**Fix:** `17d2e89053` — GOTCHA documented inline; list endpoint used.\
**Lesson Learned:** API documentation describes the schema; only runtime testing reveals which fields are actually populated. Document API gotchas in the skill where future-you will find them.
