## Day 375: SMS Group Texts, Multi-Region Backup, and Safety Nets (October 11, 2026)

### SMS Group Texts: Round 1 (GH #924)

**Commits `ef70da7a65`, `557fc99207`, `9c58618c36`, `4fb13374ca`, `ac3cea780f`, `bf87a07614`, `8835c9f505`, `039b753f23`**

Andy entered group text threads. The architecture for round 1:

**Gate design**: `@andy` in a group text triggers the gate. Friends (relationship files with `sms_access: trusted`) get a reply automatically. Strangers get silence plus a button in Alex's Discord thread to create their relationship file. Money requests — regardless of who's asking — always route through the always-ask path.

**Held texts**: Friend texts that don't auto-reply are held in sms.db and settled via "Allow Andy to reply" / "Don't reply" buttons in Discord. The held state persists across restarts.

**Stranger path**: Andy stays silent when a stranger @-mentions in a group. Alex gets a one-tap button to create their person file, enabling future auto-replies.

Three test harnesses (allow-list, Haiku-then-Jev, whole-thread) verified permission behavior against real-call cases before shipping.

### Multi-Region Backup (GH #926)

### Safety Nets: Subagent Context Meter + Bulk-Delete Guard (GH #921, #918)

**Commits `070996d9cc`, `6463b3c75a`, `a065fd9002`, `313c884dd8`, `1ea30dc982`, `1145d6060b`**

Two new safety systems:

**Subagent context meter** (GH #921 phase 3): warns before the context window fills, saving progress as it goes. When a subagent hits context death, a transcript salvage captures what was done. The subagent-chain now links continuations deterministically and reports deaths.

**Bulk-delete guard** (GH #918): a PreToolUse hook blocks bulk and silent deletes in sessions. Scheduled cleanup jobs now route bulk deletes through a quarantine script that moves files to the NAS instead of deleting them. The guard fails closed — unknown flags abort rather than proceed.

**Lesson Learned:** Two independent safety nets shipping the same day (context meter + bulk-delete guard) suggests the maturity of a system: failure modes are well enough understood to build preventive infrastructure for them.

Round 2 deepened the group text capability:

### The Mistakes We Made

#### 1. The iPostal Mailbox `#N` Collision

**Cost:** iPostal mailboxes were written as `#N` in MEMORY.md and responses, colliding with GitHub issue numbers. The Stop hook (`978f7dbbf2`) was added specifically to catch this mid-session and block the response.\
**Fix:** `492b3ef38f` — all iPostal print paths use "Box N"; the Stop hook enforces it before any response goes to Discord.\
**Lesson Learned:** Two numbering systems in the same output stream will always collide eventually. Lock the format at the source and enforce it at the output gate.

#### 2. Backup Pruning Trusted Without Verification

**Cost:** Backups were being pruned based on presence in Spaces without verifying the tarball was readable first. A silent corrupted backup could have been the only copy.\
**Fix:** `e981ee5fc3` — every base backup tarball is read back before pruning trusts it.\
**Lesson Learned:** Presence in object storage is not the same as integrity. Read-back verification before prune is the minimum bar for offsite confidence.
