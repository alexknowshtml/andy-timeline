## Reflection: Week 18

---

### The Mistakes We Made

#### 1. Context-Warning State File Trust

**Cost:** The context-warning skill initially trusted the statusline's state file for context percentage, but the file could be stale from a previous session, causing false readings
**Fix:** `9cfe67425` switched to always parsing the transcript directly for authoritative context usage data
**Lesson Learned:** State files from previous sessions are lies. Always derive current state from current data - never trust cached values across session boundaries.

#### 2. Minut Scripts Written in Wrong Language (Again)

**Cost:** Minut monitoring scripts were initially written in bash/Python, then immediately rewritten in TypeScript
**Fix:** `10d3f2913` rewrote everything in TypeScript on the same day
**Lesson Learned:** This is the same mistake as the birthday sync ENOBUFS from Week 17. When the project language is TypeScript, start in TypeScript. The rewrite tax is avoidable.

#### 3. Intent Mapping Collision: "usage"

**Cost:** "check my usage" matched both cc-hotswap (account usage) and token-usage (token analytics), causing routing confusion
**Fix:** Two disambiguation commits made triggers more specific and added conflict detection
**Lesson Learned:** Intent mapping systems need collision detection at registration time, not after users hit ambiguous routes.

### The Surprising Things

#### 1. 27,285 Tracks in One Operation

**Expected:** Importing Spotify playlists would be a multi-day, iterative process
**Actual:** 216 playlists with 27,285 tracks imported in a single bulk operation, with schema normalization and audio features added the same day

The entire music database went from zero to production-ready in one day. The bottleneck wasn't the import - it was the YouTube ID resolution, which required batch processing with human review of flagged matches.

#### 2. Compaction Resilience from a Blog Post

**Expected:** Compaction recovery would require deep Claude Code internals knowledge
**Actual:** Ben Badejo's OpenClaw article provided immediately implementable techniques (amnesia tests, snapshot triggers, tone preservation) that made sessions dramatically more resilient

External research translated directly into system improvements within hours. The techniques weren't theoretical - they were battle-tested patterns from another practitioner.

#### 3. Supplies Auto-Triage Gradient

**Expected:** Supply ordering would need either full automation or full manual review
**Actual:** The auto-triage with Discord approval created a middle path: autonomous classification + human confirmation = trust built incrementally

The pattern (detect -> classify -> propose -> approve) is reusable for any domain where full autonomy isn't appropriate yet but full manual work is wasteful.
